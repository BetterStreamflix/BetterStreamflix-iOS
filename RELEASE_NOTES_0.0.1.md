## BetterStreamflix 0.0.1

First numbered BetterStreamflix iOS drop under the BetterStreamflix organization. Unsigned IPA for sideloading — install with your own signing flow.

### Side fixes

- **Check for Updates** — shows your installed version and opens GitHub Releases for the newest IPA (no app-side secrets)
- **Support & community** — Buy Me a Coffee, Telegram, Discord, and Patreon wired in About (plus GitHub)
- **Versioning** — marketing version set to **0.0.1**; CI advances the build number on every release
- **Credits** — in-app Credits sheet with BetterStreamflix, TMDB, open-source, and community thanks
- **Splash** — full BetterStreamflix brand mark and wordmark (no leftover third-party naming)

### Premium update

- **Design system** — shared color, type, spacing, radius, motion, and surface tokens under BetterStreamflix naming
- **Library tab** — Continue Watching, Watchlist, and Watched with sort and quick actions
- **Home** — cinematic hero, Continue Watching progress rings, Watchlist shelves, TMDB discovery
- **Detail** — immersive hero, clearer Play / My List, cast carousel, seasons and episodes
- **Search** — faster results, recent searches, Discover shelves when the query is empty
- **Catalog** — Movies / Series shelves with skeleton loading and poster press motion
- **Player** — double-tap ±10s seek, vertical volume / brightness gestures, stronger chrome on top of AVPlayer, PiP, AirPlay, and skip credits
- **Settings** — grouped layout; About is the hub for version, updates, links, and credits
- **Motion & accessibility** — light haptics on primary actions; Reduce Motion–safe splash and transitions
- **Engineering** — UI split into feature modules; CI publishes IPA artifacts, GitHub Releases, and a private updates bookkeeping feed

### Get the IPA

Download **BetterStreamflix-0.0.1-unsigned.ipa** from this release (or from the matching Actions artifact).
