# BetterStreamflix iOS 0.1.2

Playback Language Picker — one spoken language drives provider enablement and player discovery.

- Single playback language (DE/EN/IT/ES/FR/PL); enables that group and disables others
- Optional Core / Anime & Stremio switch (default off)
- Player discovery and source menu hard-filtered to the active language (+ Core if on)
- Discovery ranks by the language group’s ISO code; out-of-language remembered sources ignored
- First-launch + Settings language cards with Advanced per-provider fine-tuning
- Clear empty state when no sources found for the chosen language
- Version 0.1.2
