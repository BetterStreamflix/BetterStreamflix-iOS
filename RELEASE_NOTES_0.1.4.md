# BetterStreamflix iOS 0.1.4

Next-level subtitle system expansion and general polish.

- In-player **Browse subtitle tracks** picker (Off · provider · language · sync badges) with live discovery status
- Caption **Appearance** (size, style, color) via AVTextStyleRules

- OpenSubtitles: primary + secondary language queries, richer labels
- Subtitle **cache** size/clear in Settings; Sync Studio track switcher + delete saved sync
- Empty/unavailable guidance for Sync Studio and catalogs
- More / Settings / first-launch discoverability polish
