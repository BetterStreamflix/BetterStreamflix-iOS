# BetterStreamflix iOS 0.1.11

Stremio goes next-level — real community plugins only, richer catalogs, and a proper management client.

- Remove app-bundled PenguPlay from the Stremio plugin list (migration purges it); defaults are remote manifests only
- Recommended seeds: Cinemeta, Cinemeta Popular, TMDB Addon, OpenSubtitles v3
- Popular presets: Torrentio, Comet, MediaFusion, WatchHub, Worth Watching, Wizdom/Ktuvit — graceful when unreachable
- Rock-solid install-by-URL (noisy paste, stremio://, quoted links) with health + latency
- Premium Liquid Glass plugin manager + Stremio hub with catalog search and addon filters
- Built-in HTTP stays under Core as a separate non-plugin source; NativePlayer multi-addon resolve unchanged
- Version 0.1.11
