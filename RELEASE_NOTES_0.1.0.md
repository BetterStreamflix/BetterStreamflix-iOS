# BetterStreamflix iOS 0.1.0

Full BetterStreamflix provider set on iOS.

- German VOD sources first-class (SerienStream, AniWorld, FilmPalast, Filmo, HDFilme, KinoGer, MEGAKino, Einschalten, Moflix-stream)
- English, Italian, Spanish, French, and Polish catalog scrapers as functional playback resolvers
- Shared hoster extractors (VOE, Dood, Streamtape, Vidoza, Meinecloud, …)
- OpenSubtitles added alongside SubDL / Wizdom / Ktuvit / Stremio
- First-launch + Settings: TMDB catalog, German section up front, other languages grouped
- Version 0.1.0
