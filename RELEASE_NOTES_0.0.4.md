## BetterStreamflix 0.0.4

UI stability and polish release — scrolling, chrome, logos, and page titles.

### Fixes

- **Scroll vs posters** — Poster press feedback no longer steals pans from Home / Movies / Series scroll views; taps still work
- **Featured chrome** — Brand mark stays top-left; clearer `1 / 10` counter; darker scrim behind the header for contrast
- **Title logos** — Logos restored on Featured and Detail; heroes prefer textless cover/backdrop art when a logo is available so titles are not doubled
- **Navigation chrome** — Tab bar stays visible; detail back control uses a larger hit target; interactive swipe-back works with the custom back button; Library pushed from More keeps system back
- **Series / Movies titles** — Large page titles respect the top safe area and sit under a soft contrast scrim (no collision with the status bar / clock)

### Polish

- Safer empty catalog state, consistent glass chrome, larger search / back hit targets
- Scroll bounce / indicators on primary shelves
- Longer logo resolve window on Detail; carousel asset timeout tuned for logo + textless artwork

### Install

Download **BetterStreamflix-0.0.4-unsigned.ipa** from this release (or from the matching Actions artifact).
