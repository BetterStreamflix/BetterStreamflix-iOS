# BetterStreamflix iOS 0.1.10

First-class Stremio ecosystem — install community addons, browse their catalogs, and resolve streams into the native player.

- Full Stremio addon protocol: manifest, catalog, meta, stream, and subtitles
- Install addons by HTTPS or `stremio://` URL; curated defaults (Cinemeta, PenguPlay, TMDB Addon, OpenSubtitles v3)
- Manage addons in Settings / More: enable, disable, reorder, health checks, remove
- Browse addon catalogs on Home shelves and a dedicated Addons hub (Liquid Glass, forced dark)
- Multi-addon stream + subtitle discovery into the existing NativePlayer pipeline
- Coexists with playback language providers — language scrapers stay gated by the language picker; Stremio can run independently of Core anime resolvers
- Version 0.1.10
