## BetterStreamflix 0.0.5

Chrome polish — Detail back, Featured CTAs, Search, logos, and updates sheet.

### Fixes

- **Detail back chrome** — Single floating back control; removed overlapping toolbar/system chrome and the horizontal bar across the hero; tab bar hides cleanly on Detail and restores on pop
- **Featured** — Brand sits higher; removed the top-right index control; View Details and My List are a balanced equal-height pair
- **Detail title logos** — Clear logos restore whenever TMDB has one (broader images fetch + English fallback); text only when no logo exists
- **Search** — Standalone cover with Back (no longer nested under the More tab highlight); overscroll no longer flashes a black gap
- **Check for Updates** — Cleaner glass status / notes cards, rounded sheet chrome

### Install

Download **BetterStreamflix-0.0.5-unsigned.ipa** from this release (or from the matching Actions artifact).
