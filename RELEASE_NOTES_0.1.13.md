# BetterStreamflix iOS 0.1.13

Next-level Stremio + Debrid polish — live account checks, smarter sources, and install flows that feel closer to desktop Stremio.

- **Debrid live status:** Validate Real-Debrid / AllDebrid / Premiumize / TorBox tokens with premium badges, then **Rebind** installed Torrentio / Comet / MediaFusion / AIOStreams manifests in one tap
- **Install profiles:** Fast Cached and Quality packs (cached-only, quality filters) baked into one-tap Debrid installs
- **Source command center:** Prefer `[RD+]` / cached links, binge-group continuity for next episode, size soft-caps, Cached badges in the player source menu, per-addon resolve chips on empty states
- **Honest external actions:** Open in Safari / YouTube when addons only return external or trailer links; clearer invalid-token empty-state copy
- **Configure in-app:** WKWebView configure sheet captures finished `manifest.json` / `stremio://` installs; root deep-link install confirmation sheet
- **Addon Store 2.0:** Editor’s picks plus remote community catalog fetch; AIOStreams + Torrentio ElfHosted mirror presets; update badges with Apply Update
- **Meta / catalog:** Cast + trailer merge from Stremio meta, Hub type tabs (Movie/Series/Anime/Channel), adult opt-in under Catalog, cache clear, stream-embedded subs + TMDB subtitle IDs
